# exports/

Exports reales de Shuffle (JSON del workflow tal como lo entiende el motor) se versionan aquí una vez exista una instancia real y `playbooks/isolate_kubernetes_workload.yaml` se implemente en ella (ARG-021). Hoy, `playbooks/` es la única fuente — un playbook de referencia legible por humanos, no un export de la herramienta.
